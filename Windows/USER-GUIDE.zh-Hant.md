# Windows 版 1.3.0 使用指南

版本與 macOS 1.3.0 對齊，Windows 發布標籤為 windows-v1.3.0。

## 開始使用

下載 WindowsStayAwake-v1.3.0-win-x64.exe 後直接執行；介面及圖示已內嵌。適用 Windows 10／11 x64 與 .NET Framework 4.8 以上。此版本未作商業程式碼簽署，Windows 可能顯示未知發行者提示。

1. 打開筆電蓋子並接上電源。
2. 按「開啟闔蓋運行」，等待「已開啟」及「系統實際狀態已確認」。
3. 開始 ChatGPT／Codex 工作，再闔上蓋子。
4. 初次使用請實測至少 5 分鐘，確認背景工作及網路正常。
5. 完成後先打開蓋子，再按「恢復正常模式」。之後闔蓋應按睡眠／休眠設定執行，遠端連線通常會中斷。

## 關閉功能與退出

「恢復正常模式」會停止防睡眠請求、還原設定，再把仍為「不採取動作」的插電／電池闔蓋動作改成「睡眠」。既有非零動作，例如「休眠」，會保留。

右上角 X 只隱藏視窗；程式仍在通知區運行。再開一次 EXE 會喚回視窗。

選單「結束」或 Ctrl+Q 會還原啟用前的設定並退出。若啟用前本來就是闔蓋不睡眠，單純退出仍會保留它；要改成睡眠，請先按「恢復正常模式」。

## 皮膚與語言

右下角選單提供「預設／極光磨砂／午夜藍／暖砂」和「简体中文／繁體中文／English」，選擇自動保存。Windows 標題列、字型和選單保留平台原生差異。

## 常見問題

- 關閉後仍能遠端連線：原設定可能是「闔蓋不採取動作」。在蓋子打開時按「恢復正常模式」，再闔蓋驗證。
- 視窗全黑：本版已採軟體繪製及顯示恢復重繪，請先退出舊版。
- 無法更改設定：權限或組織原則可能限制設定；顯示錯誤時不要視為啟用成功。
- 異常退出：監看程序及下次啟動會嘗試還原。恢復失敗時請保留恢復紀錄並重試。

紀錄位置：%LOCALAPPDATA%/MacStayAwake.Windows。防睡眠不保證網路或 Codex 永不中斷，也不阻止手動睡眠、重新啟動、低電量或過熱保護。電池和 Modern Standby 機種需另行實測。

## 移除

先打開蓋子，按需恢復正常模式，再從選單結束。刪除 EXE 或解壓縮資料夾即可；程式沒有安裝服務、自動啟動項目或排程。確認沒有待恢復 power-session.xml 後，才可另行刪除偏好資料。
