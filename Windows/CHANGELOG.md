# Windows changelog

## 1.3.0 — 2026-10-09

First Windows release, aligned with macOS 1.3.0.

- Native WPF controls, original coffee artwork, four themes and three languages.
- Verified AC/DC closed-lid operation and continuous execution request.
- Normal mode corrects a pre-existing Do Nothing baseline to Sleep.
- Journal, crash watcher, conditional restoration and plan-change handling.
- Reopening the executable restores the existing window.
- Software rendering addresses black client areas after display transitions.
- Standalone EXE, version metadata, ZIP, checksums and documentation.
- Build scripts, Visual Studio project, 13 regression checks and Windows CI.
